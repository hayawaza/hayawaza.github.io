Hayawaza
Excel 一覧PowerPoint 一覧プライバシー

ショートカットは、覚えなくていい。
右Shiftを押す間だけ、目の前に出る。

Hayawaza（早業）は、Excel / PowerPoint で作業中に右Shiftキーを押している間だけ、定番ショートカットの一覧を画面に重ねて表示する Windows 用の常駐ツールです。キーを離せばすぐに消えます。

Microsoft Store で見る7日間 無料で試せます

Windows 10（1809 以降）／ Windows 11 ・ デスクトップ版 Excel / PowerPoint 対応

使い方は、2つのキーだけ

1押す

右Shiftを押している間、いま前面にある Excel / PowerPoint のショートカット一覧を表示します。

2切り替える

右Shiftを押したまま左Shiftを押すと、次のカテゴリへ。最後まで行くと最初に戻ります。

3離す

右Shiftを離せば消えて、いつもの画面に。セルや図形の操作を邪魔しません。

自分好みに、安心して使える

設定

  • 呼び出しキー：右Shift / 右Alt / 右Ctrl / Scroll Lock / Pause / F12
  • 押している間だけ表示／常時表示
  • ダーク / ホワイト、透過率・サイズ・表示位置
  • Windows 起動時の自動起動

安心の設計

  • 画面共有・録画・スクリーンショットに映らない（Windows 10 バージョン 2004 以降）
  • 入力内容の記録や送信はしない。キーボードフックも不使用
  • 通信機能なし・完全オフライン・アカウント登録不要
  • クリックは下のセルや図形にそのまま届く

こんな方に

  • 罫線や整列を毎回マウスで探している
  • 一覧表を開いて調べるのが面倒
  • 資料作成を速くしたい／新人にショートカットを教えたい
  • 画面共有中に手元だけで確認したい
