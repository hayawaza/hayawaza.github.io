Excel の範囲選択・コピー・編集のショートカットキー（13個）

範囲選択とコピー、上のセルの複製など、表を作るときに毎回行う操作をまとめました。

右方向に選択拡張Ctrl+Shift+→

使いこなしのコツ

Ctrl＋Shift＋矢印キーで、データの端までまとめて選択できます。F4 は「直前の操作の繰り返し」と、数式の入力中は「参照の絶対化（$）」の2役があります。

Ctrl+B は「同時に押す」、Alt→H は「順番に押す」という意味です。

覚えなくても、作業中の画面に出せます

Hayawaza（早業）は、Excel の作業中に右Shiftを押している間だけ、このショートカットを画面に重ねて表示します。離せばすぐ消えるので、調べるために手を止める必要がありません。
